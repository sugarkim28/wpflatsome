CÀI BẢN WEB TẢI HOÁ ĐƠN TRÊN FASTPANEL – KHÔNG CẦN SSH
=====================================================

1. DNS: bản ghi A  taihoadon  →  IP của VPS (tên miền tinhoc119.com).

2. Quản lý tập tin: tạo thư mục /var/www/<user>/data/taihoadon  (NGOÀI thư mục www)
   và tải lên: taihoadon.py, chay.sh, taihoadon.env
   Xoá index.html trong thư mục www/<tên miền>.

3. Site → Cài đặt → Backend (PHP, proxy ngược, v.v.):
     Loại Backend      : Systemd
     Working subdirectory : (để trống)
     Launch command    : /bin/bash /var/www/<user>/data/taihoadon/chay.sh
     Listen type       : Host     (Port để nguyên số FASTPANEL cấp)
     Environment       : (để trống – cấu hình nằm trong taihoadon.env)
   → Lưu. Lần đầu chờ 1–3 phút để cài thư viện Python.

4. HTTPS: cấp Let's Encrypt, bật chuyển hướng HTTP → HTTPS.

5. Quản lý tập tin: mở taihoadon/data/_cau-hinh/MAT-KHAU-ADMIN-BAN-DAU.txt
   → đăng nhập https://<tên miền> bằng admin, ĐỔI MẬT KHẨU, XOÁ file txt.

Cập nhật: tải đè taihoadon.py → Backend → Lưu (khởi động lại).
Sao lưu: thư mục taihoadon/data (có khoa-bi-mat.key).
Lỗi 502: xem "Cài đặt nhật ký" / log dịch vụ; thường là chưa cài xong thư viện hoặc VPS thiếu python3.
