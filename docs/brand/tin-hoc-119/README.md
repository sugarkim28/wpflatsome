| Tệp | Dùng cho |
|---|---|
| `logo-ngang.png` | Header website (Tuỳ biến → Header → Logo), chữ ký email |
| `logo-doc.png` | Banner dọc, poster, hồ sơ năng lực |
| `logo-tron.png` | Ảnh đại diện Facebook, Zalo OA, Google Business |
| `logo-nen-xanh.png` | Nền tối: footer, slide, ảnh bìa |
| `icon-512.png`, `icon-192.png` | Biểu tượng trang web (Cài đặt → Tổng quan → Biểu tượng trang web), app |
| `anh-chia-se-1200x630.png` | Ảnh chia sẻ link lên Facebook/Zalo (og:image) |
| `goc/bo-nhan-dien.webp` | Bảng nhận diện đầy đủ (màu, font, icon, danh thiếp) |
